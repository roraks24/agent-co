# Agent Co — Frontend Studio

Interactive user interface and real-time execution monitor for the Agent Co autonomous agent platform.

## Features
- **Live Execution Studio**: Real-time visualization of agent planning, step execution, and verification.
- **Action Audit Trail**: Full inspection of tool executions, duration, input parameters, and results.
- **Session Workspace**: Integrated file explorer and editor for inspection of workspace files.
- **Configurable Prompts**: Layered prompt inspection and overrides for testing agent behaviors.

## Development

```bash
npm install
npm run dev
```

To run test suites:
```bash
npm test
```
